# ✈️ Airlines Data Analysis Project

## 📌 Project Overview

This project analyzes airline data using MySQL and Microsoft Excel.
The main objective is to clean, analyze, and visualize airline data
to generate meaningful business insights.

## 🛠️ Tools & Technologies

- MySQL
- Microsoft Excel
- SQL
- Data Cleaning
- Data Analysis
- Excel Dashboard

## 🎯 Project Objectives

- Clean and prepare airline data
- Perform data analysis using SQL
- Analyze airline performance
- Identify important business insights
- Create an interactive Excel dashboard
- Present the results using charts and KPIs

## 📂 Project Structure

- Data – Raw and cleaned datasets
- SQL – SQL queries used for analysis
- Excel – Excel dashboard
- Images – Dashboard screenshots

## 📊 Key Analysis

The project includes analysis of:

- Total Flights
- Total Passengers
- Airline Performance
- Flight Status
- Revenue
- Popular Routes
- City/Route Analysis
- Monthly Trends

## 📈 Dashboard

An interactive Excel dashboard has been created to visualize
important airline KPIs and trends.
